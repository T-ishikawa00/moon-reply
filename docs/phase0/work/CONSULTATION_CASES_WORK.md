# CONSULTATION_CASES_WORK.md

## 目的

Phase 0で実際に使用する相談ケースを記入する作業ファイル。

このファイルには、実在に近い返信待ち・追いメッセージ・曖昧な関係の相談ケースを匿名化して記入する。

重要：

- CodeXは相談内容を勝手に生成して埋めない
- 相談内容は人間側が検討して記入する
- 実名・住所・勤務先・学校名・電話番号・SNS ID・LINE IDなどは入れない
- 外部公開用サンプルには、この実相談をそのまま使わない

## 記入ルール

### 状況

以下を含める。

- 相手との関係
- 最後に連絡した時期
- 相手の返信状況
- ユーザーが今どう不安なのか
- 送ろうとしている背景

### 送ろうとしているメッセージ

できるだけ原文に近く残す。
ただし、個人情報は削除する。

### 仮判定

以下の4つから選ぶ。

- 送っていい
- 軽く送るならあり
- 今夜は待つ
- 今日は送らない方がいい

### 危険フラグ

通常ケースでは原則 `none`。
危険要素がある場合は通常相談から外し、危険系ケースに移す。
