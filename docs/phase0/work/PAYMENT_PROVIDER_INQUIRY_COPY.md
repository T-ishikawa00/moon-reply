## サービス説明

```text
AIを用いた恋愛鑑定書の単発販売サービスを検討しています。

サービス内容は、返信待ち・追いメッセージ・曖昧な関係などで不安を感じているユーザーが、
現在の状況や送ろうとしている文面を入力し、
それに対してAIを用いて「送る/待つ/軽く送る/送らない」などの方針を含む鑑定書形式の文章を生成・納品するものです。

位置づけは、占い・エンターテインメント・感情整理を目的としたサービスです。

医療、カウンセリング、診断、法律助言、確実な未来予測、相手の本心の保証を提供するものではありません。

初期販売形式は、1鑑定ごとの都度決済です。
価格は1鑑定980円を予定しています。
コイン制・ポイント制・継続課金による引き延ばしは行いません。
```
