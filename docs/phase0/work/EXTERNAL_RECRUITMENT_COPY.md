# EXTERNAL_RECRUITMENT_COPY.md

## 目的

Phase 0で25〜34歳女性5人に外部評価を依頼するための募集文・依頼文の作業ファイル。

このファイルは草案であり、実際の募集投稿は人間が確認してから行う。

---

## 募集条件

対象：

- 25〜34歳前後の女性
- 恋愛相談、占い、マッチングアプリ、復縁、曖昧な関係、電話占いに関心がある人を優先

人数：

- 5人

報酬目安：

- 1人300〜500円

作業内容：

- サンプル鑑定書を読む
- 簡単なアンケートに答える
- 所要時間：10〜15分程度

---

## 募集文案

```text
恋愛サービス案のサンプル評価にご協力いただける方を募集します。

返信待ち・追いメッセージ・曖昧な関係で不安になる夜に、
「このメッセージを送っていいか」「今は待つべきか」を鑑定書形式で返すサービス案です。

サンプル鑑定書を読んでいただき、
「自分ごとに感じるか」「保存したいと思うか」「980円なら使う可能性があるか」などを率直に回答していただきます。

対象：
・25〜34歳前後の女性
・恋愛相談、占い、マッチングアプリ、復縁、曖昧な関係などに関心がある方

所要時間：
10〜15分程度

報酬：
TBD

注意：
医療・カウンセリング・診断ではなく、占い・エンタメ・感情整理を目的としたサービス案の評価です。
```

## 依頼文案

```text
この度はご協力ありがとうございます。

以下のサンプル鑑定書を読んで、アンケートにご回答ください。

評価していただきたいポイントは、文章の上手さだけではありません。

特に見ていただきたいのは、

・自分ごとに感じるか
・保存したいと思うか
・980円なら使う可能性があるか
・ChatGPTに相談する場合と違う価値を感じるか
・胡散臭い、不安を煽っている、不快だと感じる部分があるか

です。

率直な意見をいただけると助かります。
```
