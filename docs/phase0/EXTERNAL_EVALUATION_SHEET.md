# EXTERNAL_EVALUATION_SHEET.md

## 目的

25〜34歳女性を中心に、「月の返事」の鑑定書が刺さるかを外部評価するためのシート。

自己採点だけで進めない。
ターゲットに近い人から評価を取る。

対象：

- 25〜34歳前後の女性
- 恋愛相談、占い、電話占い、マッチングアプリ、曖昧な関係、復縁相談などに関心がある人を優先

人数：

- 5人

報酬目安：

- 1人300〜500円

- ゴールド鑑定書3本
- サンプルLPコピー
- サービス説明文
