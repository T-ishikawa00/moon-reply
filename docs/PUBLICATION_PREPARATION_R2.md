# 公開準備 R2 の確認結果

GitHubの公開準備として、既存の実装・資料とR1の履歴安全化候補を維持しています。現在は隔離ローカル候補で、GitHubの履歴更新・PR閉鎖・Public化は未実施です。

## 本人確認済み

作者・committerメールの公開は本人承認済みです。メール匿名化を目的とする履歴変更は行っていません。

株ステの証券API・取引用パスワード、Discord Webhook、J-Quants、Google OAuthの旧認証情報は HUMAN_CONFIRMED_REVOKED です。実接続・再発行は行わず、不要な秘密値を候補履歴から除外した状態を維持します。本人の取引記録と第三者市場データは区別します。

## GitHubへの適用は別工程

全ブランチ・tagの旧SHAと候補SHAを固定した移行計画を、リポジトリ外のR2報告に作成しています。GitHub管理のPR参照・cacheは通常のforce pushで除去済みにはできません。株ステの旧履歴に残る第三者市場データは、失効済み認証情報とは別に公開前の対処が必要です。

R1資料のHOLD/PENDINGは当時の確認状態です。本人承認に関する現時点の状態はこのR2文書と[確認記録](publication-approval-r2.json)を参照してください。既存外部資産の非同梱・歴史的テストの再実行制限は、権利やメールの保留と分けて説明しています。
