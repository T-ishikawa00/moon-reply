## Product principle

JPY980 value is not established by word count, a fixed section count, repeated reassurance, a repeated conclusion, generic aftercare, decorative detail, or unsupported insight.

JPY980 value is established by consultation-specific understanding, grounded evidence interpretation, explainable decision logic, concrete action utility, draft utility when applicable, bounded uncertainty, an observable reassessment trigger, and emotional reassurance without false certainty.

There is no fixed word minimum and no fixed section minimum. Section-count padding is prohibited. Analytical or instructional primary blocks must own distinct Product functions and add new grounded propositions. Emotional or ritual primary blocks instead must perform distinct consultation-specific functions; they do not need to add new factual propositions.

## Semantic Depth Contract

| ID | Product value function | Contract |
| --- | --- | --- |
| A | consultation_core | State what the user is actually deciding or fearing, using only supplied input. |
| B | evidence_and_significance | Select observed facts and explain why each selected fact matters to the current decision. |
| C | decision_logic | Show observed facts → bounded interpretation → selected current direction. |
| D | alternative_tradeoff | Only when another action is genuinely plausible, explain benefits and risks of selected and unselected actions without inventing the other person's inner state. |
| E | action_artifact | Provide a concrete next action and an exact draft only when requested and permitted. |
| F | uncertainty_boundary | State what cannot currently be known; do not enumerate immaterial negative possibilities. |
| G | reassessment_trigger | Name an observable condition that changes or reopens the decision. |
| H | emotional_containment | Acknowledge the user's actual supplied fear or tension and give a consultation-specific calm stopping point for the present moment, without generic filler or false certainty. |

Mandatory Ready functions:

- consultation_core
- evidence_and_significance
- decision_logic
- action_artifact
- emotional_containment
- at least one of uncertainty_boundary or reassessment_trigger

Baseline emotional_containment must be consultation-specific, grounded in the supplied concern, acknowledge the user's actual fear or tension, and give a calm stopping point for the present moment. It must not promise the other person's feeling, reply, reconciliation, or outcome; use generic therapy filler; add unsupported certainty or an invented inner state; or disguise a repeated conclusion as reassurance. A logically complete but emotionally cold Report cannot be full_paid_ready.

Conditional functions:

- alternative_tradeoff
- draft
- message impact
- additional emotional containment depth

Grounding failure is state-aware. If the clarification budget is unused and one answer can determine materiality, route to needs_one_clarifying_answer. If the budget is exhausted and mandatory functions are still not groundable, or the consultation itself is non-material, route to not_full_product_candidate. Safety routes to safety_blocked. Groundable mandatory functions permit a full_paid_ready candidate. Insufficiency must not loop indefinitely through needs_more_information. A longer answer or additional section cannot substitute for a missing function.

## Grounding boundary

Semantic deepening explains Moon Reply's recommendation. It does not invent the other person's cause, chronology, inner state, future reply, or relationship outcome.

Prohibited unless directly supported by Base facts:

- 相手は忙しいから返信していない
- 相手はあなたを嫌っていない
- 相手は慎重になっている

Allowed only when the corresponding supplied evidence supports the statement:

- 返信がない理由は現在分からない
- 最後の連絡からまだ短時間
- 拒絶や終了を示す事実はない
- 追加送信で増える情報がない
- therefore current recommendation is to wait

The recommendation may explain how observed evidence supports an Application decision. It may not turn absence of evidence into a positive claim about hidden feelings.

## Non-repetition contract

Analytical or instructional primary blocks each must add at least one new grounded proposition, own a distinct Product function, and avoid rephrasing a prior conclusion. This applies to evidence_and_significance, decision_logic, alternative_tradeoff, action_artifact, uncertainty_boundary, and reassessment_trigger.

Emotional or ritual primary blocks do not need to add a new factual proposition. Each must instead perform a distinct consultation-specific emotional or ritual function. openingLetter, emotional_containment, and closingLines must not repeat the selected decision or action instruction, add unsupported facts, use generic filler, or create false certainty.

Good emotional function: 「今夜の沈黙だけで、この関係の答えまで決める必要はありません。」

Bad repeated decision: 「今は待ちましょう。今日は待つだけで大丈夫です。」

Future deterministic controls may detect:

- exact normalized duplicates
- a source field reused in multiple primary locations
- a repeated internal proposition ID

Proposition IDs are audit-only and must never become customer-visible. Semantic repetition that cannot be proved deterministically remains a mandatory Human Product Review item.
