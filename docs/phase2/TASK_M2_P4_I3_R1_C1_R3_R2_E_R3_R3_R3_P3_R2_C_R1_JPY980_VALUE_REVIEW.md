## Product principle

JPY980 value is not established by word count, a fixed section count, repeated reassurance, a repeated conclusion, generic aftercare, decorative detail, or unsupported insight.

There is no fixed word minimum and no fixed section minimum. Section-count padding is prohibited. Every visible primary paragraph or list group must own a distinct Product function and add at least one proposition that no prior primary block has delivered.

## Semantic Depth Contract

| ID | Product value function | Contract |
| --- | --- | --- |
| A | consultation_core | State what the user is actually deciding or fearing, using only supplied input. |
| B | evidence_and_significance | Select observed facts and explain why each selected fact matters to the current decision. |
| C | decision_logic | Show observed facts → bounded interpretation → selected current direction. |
| D | alternative_tradeoff | Only when another action is genuinely plausible, explain benefits and risks of selected and unselected actions without inventing the other person's inner state. |
| E | action_artifact | Provide a concrete next action and an exact draft only when requested and permitted. |
| F | uncertainty_boundary | State what cannot currently be known; do not enumerate immaterial negative possibilities. |
| G | reassessment_trigger | Name an observable condition that changes or reopens the decision. |
| H | emotional_containment | Provide consultation-specific acknowledgment and closure without generic therapy filler or false certainty. |

Mandatory Ready functions:

- consultation_core
- evidence_and_significance

- at least one of uncertainty_boundary or reassessment_trigger

Conditional functions:

- alternative_tradeoff
- draft
- message impact

## Grounding boundary

Semantic deepening explains Moon Reply's recommendation. It does not invent the other person's cause, chronology, inner state, future reply, or relationship outcome.

Prohibited unless directly supported by Base facts:

- 相手は忙しいから返信していない
- 相手はあなたを嫌っていない
- 相手は慎重になっている

Allowed only when the corresponding supplied evidence supports the statement:

- 返信がない理由は現在分からない
- 最後の連絡からまだ短時間
- 拒絶や終了を示す事実はない
- 追加送信で増える情報がない
- therefore current recommendation is to wait

The recommendation may explain how observed evidence supports an Application decision. It may not turn absence of evidence into a positive claim about hidden feelings.
