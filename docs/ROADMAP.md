# ROADMAP.md

## Overview

月の返事は、検証MVPから段階的に開発する。

いきなり本番Webアプリやネイティブアプリを作らない。
Phase 0〜Phase 1で需要と鑑定品質を検証し、Go条件を満たした場合のみWeb MVP実装へ進む。

## Phase 0: AI鑑定品質ラボ

目的：鑑定書そのものが課金に値するか検証する。

作るもの：

- 相談ケース10〜15件
- 危険系ケース3〜5件
- 4判定基準表
- ゴールド鑑定書3本
- プロンプトv1
- 禁止表現リスト
- 外部評価シート

Go条件：

- 外部評価5人中2人以上が「保存したい」
- 1人以上が「¥980なら払う可能性あり」
- 危険ケースで安全分岐できる
- 判定が安定している

## Phase 1: 半自動¥980有料検証

目的：見知らぬ人が¥980払うか検証する。

作るもの：

- LP
- 決済導線
- 鑑定依頼シート
- AI生成 + 人間確認
- メール or 専用URL納品
- フィードバック回収

価格：

- 1鑑定¥980

## Phase 1.5: 半自動Web納品MVP

目的：手動負荷を減らしつつ品質確認を残す。

作るもの：

- 管理画面
- 相談一覧
- AI生成ボタン
- 鑑定書編集
- 鑑定書URL発行

## Phase 2: 自動Web MVP

目的：入力→決済→AI生成→鑑定書表示を自動化する。

作るもの：

- LP
- 鑑定依頼シート
- 決済
- AI安全判定
- AI構造化
- 4判定
- 鑑定書生成
- 鑑定書表示
- 保存用URL
- 管理ログ

## Phase 3: 相手別ノート

目的：単発課金から継続利用へ進める。

作るもの：

- ログイン
- partner_id
- 相手別ノート
- 過去鑑定一覧
- 3日後フォロー
- 前回からの変化分析

## Phase 4: 低額サブスク

目的：月額¥980〜1,500の継続収益を検証する。

価値：

- 月3〜5回鑑定
- 相手別ノート1人
- 過去ログ保存
- 3日後フォロー
- 保存無制限
- 広告なし

## Phase 5: ネイティブアプリ

目的：Webで継続需要が見えた後に、スマホ体験を強化する。

作るもの：

- Expo React Native app
- App Store IAP
- Push通知
- ノートUI
- 鑑定書保存

## Phase 6: 月額4,000円級プレミアム

目的：高頻度ユーザーに恋愛ノートOSとして売る。

価値：

- 1日1回まで通常鑑定
- 月4回の深層鑑定
- 相手別ノート5人
- 関係変化レポート
- 3日後/7日後フォロー
- 入力履歴に基づく週間分析レポート
- 保存用鑑定書
- 優先生成
