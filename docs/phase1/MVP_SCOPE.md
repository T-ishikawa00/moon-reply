# MVP_SCOPE.md

## 0. Purpose

Phase 1 MVP is a semi-manual sales validation MVP.

The goal is not to build the complete app.

The goal is to test whether real users will pay for a single “月の返事” diagnosis.

---

## 1. MVP Definition

The Phase 1 MVP consists of:

1. One-page LP
2. Diagnosis request form
3. Payment link or manual payment flow
4. Manual diagnosis generation
5. Human quality check
6. Email or URL delivery
7. Feedback collection
8. Metrics tracking

---

## 2. User-facing Experience

The user experience should feel like:

1. User lands on 月の返事 LP
2. User understands the service
3. User reads sample diagnosis/copy
4. User decides to request a diagnosis
5. User fills in a request form
6. User pays ¥980
7. User receives a diagnosis within the promised delivery window
8. User can save or revisit the diagnosis
9. User is asked for feedback

---

## 3. MVP Price

Initial price:

- ¥980 per diagnosis

Rules:

- 1相談 = 1鑑定書
- No coin/point system
- No subscription in Phase 1
- No upsell after payment
- No fear-based continuation push

---

## 4. In Scope

In scope:

- LP copy
- LP section structure
- Order/request form spec
- Payment provider candidate flow
- Manual delivery workflow
- Quality checklist
- Safety and refund notes
- Metrics template
- Feedback collection
- Operational runbook

---

## 5. Out of Scope

Out of scope:

- Login
- User account
- My page
- Partner-specific notebooks
- Diagnosis history
- Database
- AI auto-generation API
- Automatic payment API integration
- Subscription
- Coin/point system
- Native app
- Auto-generated image card
- Full dashboard
- Admin panel
- Automated email system

---

## 6. MVP Success Criteria

Primary success criteria:

- Paid orders: 10 or more within validation window
- Refund requests: 1 or less
- At least 3 users say they want to save the result or read it again
- At least 2 users show repeat intent
- “ChatGPT is enough” is not the dominant feedback

Secondary signals:

- LP viewers understand the service quickly
- Form completion is not too difficult
- Users accept manual delivery
- ¥980 is not universally rejected
- The service feels like a diagnosis note, not generic AI chat

---

## 7. MVP Failure Criteria

No-Go or major iterate if:

- LP traffic is enough but paid orders are 0〜2
- Most users say ChatGPT is enough
- Users do not understand what they are paying for
- ¥980 is strongly rejected
- Diagnosis results are not perceived as saveable
- Safety concerns appear
- Payment provider cannot be used for this category
