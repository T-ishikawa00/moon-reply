# DELIVERY_WORKFLOW.md

## 0. Purpose

This document defines the manual delivery workflow for Phase 1 MVP.

---

## 1. Workflow

1. Receive form submission
2. Check safety screening
3. Check payment status
4. Decide whether normal diagnosis is allowed
5. Generate diagnosis draft using approved style
6. Human quality check
7. Prepare saveable card copy
8. Deliver by email or private URL
9. Ask for feedback
10. Record metrics

---

## 2. Safety Branch

If dangerous content is detected:

- Do not generate normal romantic diagnosis
- Do not provide message wording that enables harm, stalking, coercion, or manipulation
- Use safety response
- Refund if payment already happened
- Record as safety-rejected case

Danger types:

- self-harm
- harm to others
- DV/abuse
- stalking/waiting outside home/workplace
- threats
- monitoring/surveillance
- minor-related romantic/meeting request
- doxxing or personal information exposure

---

## 3. Diagnosis Creation

Use approved golden samples as quality references:

- G001: waiting/reply anxiety
- G002: urge to send long follow-up
- G003: ambiguous relationship with positive alternative

Diagnosis must include:

- 今夜の月の流れ
- 今の恋の流れ
- 相手の気持ちの可能性
- 不安の核心
- 文面の届き方
- 逆効果なこと
- 今夜の判定
- 送るならこの一文
- 送らない場合/送った後の過ごし方
- 3日以内の方針
- 月からの一言
- 保存用メモ
- 感情タグ

---

## 4. Delivery Format

Initial delivery options:

- Email body
- Google Docs private link
- PDF later if needed

Recommended first delivery:

- Email body + Google Docs link

Reason:

- Easy to deliver
- Easy to edit before sending
- Easy to preserve formatting
- No app required

---

## 5. Delivery Email Template

Subject:

月の返事｜今夜の鑑定書をお届けします

Body:

```text
ご依頼ありがとうございます。
月の返事です。

今回の鑑定書を以下にお届けします。

[鑑定書URL or 本文]

この鑑定は、AIを活用した占い/エンタメ/感情整理目的の内容です。
医療・診断・カウンセリングではなく、相手の本心・返信・復縁を保証するものではありません。

よろしければ、今後の改善のために短い感想をいただけると嬉しいです。

[フィードバックフォームURL]
```
