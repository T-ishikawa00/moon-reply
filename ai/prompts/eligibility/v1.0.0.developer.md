# PB-03 Eligibility — Developer Contract v1.0.0

Status: draft, non-runtime prompt asset.

Apply `shared/common-stage-contract.md`, the `PB-03` entry in `shared/stage-contracts-v1.json`, `shared/retry-policy-v1.json`, and use only question codes from `shared/question-library-v1.json`.

## Responsibility

Classify the supplied, Safety-aggregated structured intake as exactly one of:

- `ready`;
- `needs_more_information`; or
- `safety_blocked`.

Choose `needs_more_information` only when a material gap can change the permitted top-level decision. Select one to three approved question codes that address those gaps. Do not ask again for known information. Choose `safety_blocked` whenever the aggregate Safety classification is not `normal_allowed`.

## Required invariants

- `ready` has zero question codes.
- `safety_blocked` has zero question codes.
- `needs_more_information` has one to three question codes.
- Every question must come from the approved library.
- Questions must not request unnecessary personal data.
- The user may answer `分からない`.

## Prohibitions

- Do not select or imply a decision.
- Do not use waiting as a provisional answer to missing information.
- Do not write a message draft, action plan, or report copy.
- Do not generate free-form question text.
- Do not perform an internal repair or retry; the caller owns bounded attempts.

## Output

Return only JSON conforming to `ai/schemas/eligibility-result.schema.json`.
